# DS4 Mac App

Minimal SwiftUI wrapper around the existing `ds4-agent` binary.

## Run

From the repository root:

```sh
make ds4-agent
cd mac-app
swift run DS4MacApp
```

The app starts `ds4-agent` as a child process on launch with non-interactive
mode, SSD streaming enabled, and temperature fixed at 0. Prompts entered in the
UI are written to the agent's stdin, and agent output is streamed back into the
output pane. During prompt prefill, the app shows a native progress bar above
the output pane using progress markers emitted by the agent.

## Build as an app (with icon)

`swift run` launches the bare executable, which has no Dock/Finder icon.
To get a proper `DS4MacApp.app` bundle with the DS4 icon:

```sh
cd mac-app
./build_app.sh          # pass "debug" as an argument for a debug build
open DS4MacApp.app
```

The icon (`AppIcon.icns`) matches the gradient sparkles badge shown next to
"DS4" in the app header, and is generated by `make_icon.swift`. Regenerate it
with:

```sh
swift make_icon.swift AppIcon.iconset
iconutil -c icns AppIcon.iconset -o AppIcon.icns
rm -rf AppIcon.iconset
```

## Scope

This first version intentionally avoids a native C bridge. It is meant to test
the product loop quickly: choose a model, start the local agent, enter a prompt,
and get a response.
